# 🛒 Retail Order Data Analysis

## 📌 Project Overview

This project focuses on analyzing retail order data to uncover business insights related to sales performance, profitability, customer behavior, and product trends.

The complete workflow includes:

- Data extraction using Kaggle API
- Data cleaning and preprocessing with Python
- SQL-based business analysis
- Data visualization
- Interactive dashboard creation using Streamlit

The project simulates a real-world end-to-end data analytics pipeline used in retail and e-commerce industries.

---

## 🚀 Objectives

The main goals of this project are:

- Analyze sales and profit trends
- Identify top-performing products and categories
- Discover high-revenue regions and customer segments
- Perform SQL-driven business analysis
- Build an interactive analytics dashboard
